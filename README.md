# Sales Performance & Profitability Analysis

## Project Overview
This project analyzes sales performance and profitability using SQL and Tableau. The goal is to identify top-performing product categories, regional sales trends, and shipping patterns to support data-driven business decisions.

## Tools & Technologies
- **SQL (SQLite):** Data aggregation, filtering, grouping, sorting, and profitability analysis
- **DB Browser for SQLite:** Database management and query execution
- **Tableau:** Data visualization and dashboard development

## Business Questions
1. What are the overall sales, total profit, and number of orders?
2. Which product categories generate the highest sales and profit?
3. Which regions contribute the most sales?
4. Which subcategories are the most and least profitable?
5. How do shipping modes compare in order volume, sales, and profit?

## SQL Analysis
The SQL queries cover:
- Overall sales and profitability metrics
- Sales and profit by category
- Regional sales and profit comparisons
- Subcategory profitability analysis
- Order volume and performance by shipping mode

## Key Findings
- Technology generated the highest sales among the product categories.
- The West region had the highest total sales among the regions analyzed.
- Standard Class was the most frequently used shipping mode by order count.
- Profitability varied across product subcategories, highlighting areas for further investigation.

## Repository Contents
- `sales_analysis.sql` — SQL queries used for the analysis
- `sales_analytics.db` — SQLite database containing the analysis data

## How to Use
1. Download or clone this repository.
2. Open `sales_analytics.db` using DB Browser for SQLite.
3. Open `sales_analysis.sql` and execute the queries.
4. Review the query results and use them to build visualizations in Tableau.

## Skills Demonstrated
SQL querying, data aggregation, business analysis, profitability analysis, database management, and data visualization.
